# Kyle A. Rains — personal website

A single-page, dependency-free static site (plain HTML + one CSS file) with a
cartographic theme. Ready to publish free with GitHub Pages.

## Files

| File | What it is |
|------|-----------|
| `index.html` | The whole site (Home, Research, CV, Contact sections) |
| `style.css` | Design — colors, fonts, the map graticule, compass rose |
| `cv.pdf` | **Add this** — your CV, so the "Open CV (PDF)" buttons work |

## Add your CV

Save your CV file into this folder named exactly **`cv.pdf`**. Every "Open CV (PDF)"
button links to it and opens it in a new browser tab.

## Edit content

Open `index.html` in a text editor and edit the text directly. To change colors or the
map styling, edit the tokens at the top of `style.css`.

## Publish (GitHub Pages)

1. Create a public repository (e.g. `kyle-website`).
2. Upload every file in this folder (including `cv.pdf`).
3. Repo **Settings → Pages → Source: main branch → Save**.
4. Live within a minute or two at the URL GitHub shows.
